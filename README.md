# TDR_V2
La Veritat Darrere de la IA

Aquest projecte forma part del meu Treball de Recerca (TDR) sobre la intel·ligència artificial i el seu funcionament real.

L’objectiu principal és entendre com funciona una IA moderna, com aprèn, com genera respostes i quina relació té amb conceptes com les xarxes neuronals i el machine learning.

A més de la part teòrica, el projecte inclou una interfície web connectada a una simulació visual feta amb Python que representa una xarxa neuronal artificial.

Tecnologies utilitzades
HTML
CSS
JavaScript
Python
Ursina Engine
WebSockets
OpenRouter API
Com funciona

La web envia missatges a una IA utilitzant la API de OpenRouter.

Quan la IA respon:

la resposta es mostra a la pantalla
i simultàniament s’activa la simulació neuronal en Python

La simulació representa connexions entre neurones artificials de manera visual.

Instal·lació
Instal·lar dependències de Python
pip install ursina websockets
Executar la simulació neuronal
py neuralnetworktest.py
Obrir la web

Obrir el fitxer:

index.html
Configuració de la API

Per seguretat, la API Key no està inclosa en aquest repositori.

OpenRouter

Obrir el fitxer:
app.js
